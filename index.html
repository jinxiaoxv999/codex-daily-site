LOCAL DESKTOP REPORTING

让广告日报从数据整理中解放出来

Codex日报面向广告投放团队，在用户自己的 Mac 上读取经授权的 TikTok 广告数据和客户后台报表，生成昨日数据看板与 Excel 日报。

了解工作方式查看隐私政策 →

读取必要数据

应用只读取生成报表所需的广告消耗、ROAS 和广告 ID 等字段，并按 ID 匹配数据。

本机处理

第一版在用户自己的电脑上运行，数据和授权凭据保存在本机，不经过本产品的服务器。

只读操作

应用用于报表和核查，不创建、修改、暂停广告，也不调整广告预算。

适用对象

本工具供获得相应广告账户和客户后台授权的广告投放人员使用。使用前请确认你有权访问相关数据。
